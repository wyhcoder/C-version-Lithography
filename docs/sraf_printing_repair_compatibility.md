# 当前 SRAF printing 修复方法的兼容风险

## 直接 AI 检测

按用户要求恢复直接比较连续 AI 与源 `resist.threshold` 的方法，检测、统计和选块使用严格 `AI>threshold`。
已锁定 SRAF 的停止目标为 `threshold-intensity_margin`，余量由 YAML 指定。
原几何方法 `single_sraf_multi_pair` 保留，新增 `single_sraf_normal_gradient` 供 YAML 选择。

## 接口与配置

- YAML 删除 `wi_limit`，恢复 `intensity_margin`，缺省余量为 0.01。
- 已移除 WI 反解 AI 的公开工具和对应测试；外部调用此实验工具的代码需要移除调用。
- 选块函数的参数类型不变，阈值参数明确表示源 AI 显影阈值。
- summary 删除 WI 上限、反解 AI 上限和 WI 达标字段，恢复直接 AI 的阈值及安全目标含义。
- 旧 WI 方案的 YAML 请删除 `wi_limit` 并改用 `intensity_margin`；该旧字段不再读取。
- 源显影模型不变；两种方法均已移除 mask 栅格连通性与孔洞数检查，没有新增第三方依赖。
- 删除实验工具接口 `preserves_sraf_raster_components` 及对应测试，项目内没有其他调用方。
- summary 删除 `initial_material_components`、`final_material_components`、`initial_holes`、`final_holes`
  和 `preserves_each_4_and_8_connected_component`；读取这五项的外部脚本需要同步调整，项目绘图脚本不依赖它们。
- 当前 YAML 选择新梯度方法，输出到 `matrix_0003_normal_gradient`；严格复用指定目录，重复运行覆盖同名文件。
- 配置快照、主图形控制点、TXT/CSV、日志和图片均允许覆盖，不自动追加版本号，不清空目录中的其他文件。
- 已在已有输出目录上实际复跑：未创建新目录，同名输出成功覆盖，26 个数值文件及 summary 与修改前一致。
  固定目录验证记录为 `output_directory_verification.json`，自动 WI 对比图生成正常。

## 自动生成 WI 对比图

Demo 关闭全部记录文件后自动调用绘图脚本，使用本次实际输出目录。
`comparison.png` 继续展示连续 WI 的全图、局部和剖面对比，以及真实参数化曲线和控制点。
前后色阶固定为 `[0,1]`，红线 `WI=0.5` 仅用于显示，修复判据直接读取 AI。

绘图脚本不再读取 WI 方案的上限字段，历史 WI 结果请使用其原始图像。

## 新增法向差分梯度方法

- 模式省略时仍采用原几何方法；新 YAML 显式设置 `single_sraf_normal_gradient`，原参数值保留。
- 新增固定窗口平方超限损失及整块控制点法线接口；几何方法复用相同 CR 法线公式，数值顺序不变。
- 新方法是串行中心差分，实际更新只保留内向负梯度，仅按 step_px 限幅，再整体回退。
- 新方法只检查周期 CR 闭合、采样曲线无自交及本块损失下降；不再因栅格连接、孔洞数、面积或厚度拒绝更新。
- 新方法的 EPE 和全局 printing 仅记录，不作为接受条件；原几何方法保留面积、EPE 和全局 printing 检查。
- 新增 first_gradient.csv 和控制台首轮逐点输出，梯度是原始法向导数，不包含学习率或回退缩放。
- 新增 CSV/窗口/梯度收敛图；原方法的 TXT/CSV 格式保持不变，新模式增加梯度元数据；summary 的删除字段见上文。
- 没有增加第三方依赖。新方法每轮通常额外做两倍控制点数的完整成像，耗时明显高于几何方法。

## 方法边界

1. 选组和步长回退为几何启发式，不保证所有版图收敛。
2. 最宽截面仍采用 1/8 pixel 网格估计宽度；采样曲线自交检查不等价于完整连续 MRC。
3. 背景范围沿用主图形 Guard 外及 Guard 内独立 AI 超阈值区域，并非全部原始背景像素。
4. 每次接受前完整成像；新梯度方法记录 EPE/背景 printing，原几何方法仍检查其上限。
5. 分组只支持外轮廓及一层孔洞；两种方法均允许 mask 栅格连通数变化，以周期 CR 闭合和采样自交检查约束曲线。
6. 当前实际版图验证为 matrix_0003，未验证剂量/离焦窗口、全芯片性能或像素间连续峰值。
7. 当前环境为 OpenCV 5，沿用项目的 OpenCV 4/5 条件包含，未在 OpenCV 4 环境另行构建。
